# orphaner/homebrew-tap

Homebrew formulas for my tools, on macOS and Linux (WSL included).

```bash
brew install orphaner/tap/omnitail
```

| Formula | |
|---|---|
| [omnitail](https://github.com/orphaner/omnitail) | follow many log streams at once, in stacked panes: files, commands, docker, compose, kubernetes |

Formulas in `Formula/` are written by each project's release workflow: don't edit them by hand.
